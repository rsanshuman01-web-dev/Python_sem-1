# Weather Data Visualizer – Anshuman Sharma

## Project Overview
This project analyzes real-world weather data from the Daily Delhi Climate Dataset and visualizes temperature, humidity, and seasonal trends using Python.

## Tools Used
- Python (Pandas, NumPy, Matplotlib)
- Jupyter Notebook (optional)
- CSV data processing

## Project Structure
weather-data-visualizer/
├── data/
│   └── DailyDelhiClimateTrain.csv
├── src/
│   └── weather_analysis.py
├── output/
│   ├── cleaned_weather_data.csv
│   └── *.png
├── README.md
└── REPORT.md

## How to Run
Open Terminal and run:

cd ~/Documents/weather-data-visualizer/src
python3 weather_analysis.py

- cleaned_weather_data.csv
