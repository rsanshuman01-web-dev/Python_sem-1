# Weather Data Analysis Report

## Author
Anshuman Sharma

## Introduction
This report analyzes temperature and humidity data using the Daily Delhi Climate Dataset. The goal is to clean the data, compute statistics, and visualize weather patterns.

## Data Cleaning
- Date column converted to datetime format
- Removed missing or invalid values
- Renamed columns for clarity
- Saved cleaned data as cleaned_weather_data.csv

## Statistical Insights
- Mean Temperature: ~25.5°C
- Min Temperature: 6°C
- Max Temperature: 38.7°C
- Standard Deviation: ~7.3°C

## Visualizations
1. Daily Temperature Trend
2. Monthly Average Temperature
3. Humidity vs Temperature Scatter Plot
4. Combined Plot (Line + Scatter)

## Conclusion
The dataset shows clear seasonal variation: summer peaks in May–June and winter dips in Dec–Jan. Humidity and temperature show a negative correlation.
