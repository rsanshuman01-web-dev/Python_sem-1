## 📌 Project Description  
This project analyzes real-world daily weather data using Python.  
It demonstrates your ability to:

- Load CSV datasets using Pandas  
- Clean data (NaN handling, type correction, datetime conversion)  
- Perform numerical analysis with NumPy  
- Group and aggregate data (daily, monthly, yearly trends)  
- Create meaningful data visualizations using Matplotlib  
- Export cleaned datasets and graphs  
- Present the results in a structured report  

This assignment brings together everything you learned this semester in Python programming, data manipulation, and visualization.
